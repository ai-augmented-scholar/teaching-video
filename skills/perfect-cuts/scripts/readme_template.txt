PERFECT CUTS — YOUR EDITED VIDEO PACKAGE
=========================================
Skill Created by Vic Laranja. Get more Free Creator Skills at https://skool.com/vic

Your raw clip was cut down automatically: retakes removed, false starts
caught, dead air stripped. Every file in this folder is the SAME edit,
in a different format.

START HERE

1 WATCH - final video (C).mp4
   The finished cut as a normal video. Watch it first.
   THIS IS THE FILE FOR iMOVIE (and for any editor):
   - iMovie: import this MP4 as media and drag it onto the timeline.
     iMovie cannot open the timeline files (XML, FCPXML, EDL) below;
     the MP4 is the iMovie route.
   - Captions: file 6 (the .srt) is timed to this video.

MORE FILES (for editors that read timeline files)

2 EDIT - Final Cut Pro (C).fcpxml
   The cut as an editable Final Cut timeline (links to your ORIGINAL clip).
   - Final Cut Pro:  File > Import > XML... > pick this file
   It lands in an event called "Perfect Cuts" as a new project.
   Every cut point stays adjustable.

3 EDIT - Premiere + Resolve (C).xml
   The same timeline in the older FCP7 XML format, which is what Premiere
   and Resolve read. Final Cut CANNOT open this one - use file 2 instead.
   - Premiere Pro:     File > Import > pick this file
   - DaVinci Resolve:  File > Import Timeline > pick this file

4 REVIVE - cut decisions (C).csv
   Open in Numbers, Excel or Google Sheets. Every line of your raw clip,
   whether it was KEPT or CUT, and why. If a line was cut that you
   wanted, tell Claude "revive block [number]" and the package
   gets re-exported with it back in.

5 OPEN IN REMOTION - Mac (C).command
   Double-click to open the edit in Remotion Studio (free, code-based
   video tool). Needs Node.js installed (the launcher tells you if it's
   missing). First run installs Remotion - takes a few minutes.

6 CAPTIONS (C).srt
   Subtitles timed to the EDITED video (file 1). Upload it next to the
   video on your course site, or import it into any caption-friendly tool.

7 AVID + LEGACY (C).edl
   Old-school timeline format for Avid and other pro apps.

cut data (C).json
   The raw cut points (machine-readable). Powers the Remotion launcher
   and any automation. Leave it in this folder.

GOOD TO KNOW
------------
- The XML files, the EDL, and the Remotion launcher all point at your
  ORIGINAL raw clip. If you move or rename that clip, re-link it in your
  editor (or drop the raw clip into this folder for the Remotion launcher).
- The MP4 (with its SRT) is the only pair that works standalone forever.
